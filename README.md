# 桌面时钟 / 课表终端（ESP32-C3）

128×64 OLED 桌面时钟：时间、精确时钟、正计时、倒计时、课表、离线阅读器。
零依赖固件，只用 ESP32 自带外设；字库放进独立 flash 分区 mmap，不占 RAM。
配置全部走蓝牙（手机 App），设备自己不开热点、不联网。

## 硬件

| 部件 | 连接 | 说明 |
|---|---|---|
| SSD1306 128×64 | SDA **GPIO6** / SCL **GPIO7** | I2C，0x3C，400kHz，分块 64 字节写 |
| DS3231 | 与屏幕同一 I2C 总线 | 0x68，RTC 掉电走电池 |
| 按键 K1 | **GPIO5** → GND | `*` |
| 按键 K2 | **GPIO10** → GND | `0` |
| 按键 K3 | **GPIO20** → GND | `1` |
| 按键 K4 | **GPIO4** → GND | `#` |
| 调试串口 | GPIO21 TX | 只发日志，115200 |

按键内部上拉、低电平有效，长按 700ms 起连发（每 120ms 一次）。
C3 的 Flash 走 GPIO12–17，上面这些脚都不冲突。

## 编译烧录

> **日常一律走 GitHub CI**：本地全量编译要 20 分钟以上，CI 约 1 分半。
> `git push` → Actions 里 `build` workflow（手动触发）→ `./getfw.sh` 把产物拉到
> `/sdcard/Download`。App 改动走 `android` workflow，产物用 `./getapk.sh` 拉。

fqbn 后面**必须带 `:CDCOnBoot=cdc`**，否则板载 Type-C 看不到任何串口输出
（C3 默认 `Serial` = UART0 GPIO20/21，与原生 USB 不通）。

```bash
arduino-cli compile --fqbn esp32:esp32:esp32c3:CDCOnBoot=cdc .
arduino-cli upload  -p /dev/ttyACM0 --fqbn esp32:esp32:esp32c3:CDCOnBoot=cdc .
arduino-cli monitor -p /dev/ttyACM0 -c baudrate=115200
```

| 产物 | 刷写地址 | 用途 |
|---|---|---|
| `oled_test.ino.bin` | `0x10000` | 只换固件，字库、书库、NVS 都保留 |
| `oled-full.bin`（4MB 整包） | `0x0` | 含字库；**会清掉 NVS、绑定和书库** |

分区表改过、字库变大时只能刷整包；只刷 app 时固件与字库必须同一版，
否则字库 mount 会自己判定不匹配并关掉（屏幕不出字，日志里有一行提示）。

## 按键总规则

| 操作 | 效果 |
|---|---|
| 长按 `*` | 任何页面回主页；在主页则回到「上次应用」 |
| 短按 `*` | 各页面自定义（主页 = 息屏） |
| 长按 `#`（主页） | 进编号输入 |
| 息屏 | 长按 `0` 或 `1` 唤醒；30 秒无操作自动息屏（正计时/倒计时运行时持锁，不会黑屏） |

### 耗电

- 息屏后**完全不读 RTC**（原来每秒读一次），唤醒时补读一次再显示，看到的永远是刚读到的时间。
- 主页静止（走马灯不滚、秒数没变）时不出帧，只有秒变才重画；滚动时仍按 45ms 一步。
- 主循环末尾让出 CPU（亮屏 1ms、息屏 8ms 一睡），空转时进 WFI，不再 160MHz 满跑。
- 想再往下压只能上 light sleep，但那会断开 USB CDC 串口和 BLE，暂不做。

## 界面

### 主页

第 1 行 `26.11.24-周一`，第 2 行大号 `21:04:37`，第 3 行留白，第 4 行走马灯显示课表状态：

```
正在上 高等数学，还剩 23分，下节 大学英语
下节 高等数学，还有 45分，下下节 大学英语
正在上 高等数学，还剩 23分
下节 高等数学，还有 45分
今天的课都上完了
今天没课
```

- 不加「上课：/下课：」前缀，时态由「正在上 / 还剩 / 下节 / 还有」表达。
- 没有下节（或下下节）时整段省掉，不会显示「无」。
- 后面按时间由近到远追加最多两条全局事件，形如「1小时20分后 放学 18:40」。

| 按键 | 效果 |
|---|---|
| `0` / `1` | 调暗 / 调亮（长按连续），0–100 档，寄存器值 <10 不落盘（太暗看不见） |
| 短按 `*` | 息屏 |
| 短按 `#` | 进菜单 |

### 菜单（5 项）

`主页 / 精确时钟 / 正计时 / 倒计时 / 课表`，`0`/`1` 移动，`#` 进入，`*` 返回。
阅读器与蓝牙配置不在菜单里，靠编号进。

### 编号输入（主页长按 `#`）

`0`/`1` 输入二进制位，`#` 确认，`*` 返回。前导 0 不影响结果：

| 编号 | 应用 | | 编号 | 应用 |
|---|---|---|---|---|
| `0` | 主页 | | `100` | 阅读器（隐藏） |
| `1` | 精确时钟 | | `101` | 蓝牙配置 |
| `10` | 正计时 | | `111` | 课表 |
| `11` | 倒计时 | | | |

隐藏应用（当前只有阅读器）**只能**用「前缀 `10010011` + 编号」进：
前缀满 8 位后自动转入隐藏模式，之后输入的位不显示，输入 `10010011 100` 才进阅读器。
用普通方式输入 `100` 会被判无效；反过来隐藏应用也不会进「上次应用」。

隐藏应用**息屏即退出**：自动息屏或 `light off` 后自动回到主页，唤醒看到的是主页，
不会留着一本打开的书给别人看。

### 精确时钟 / 正计时 / 倒计时

| 页面 | 按键 |
|---|---|
| 精确时钟 | 只显示，无操作 |
| 正计时 | `#` 开始/暂停，`*` 清零 |
| 倒计时 | 暂停时 `0` 加 1 分、`1` 加 1 秒（长按连加），`#` 开始/暂停，`*` 清零 |

正计时、倒计时运行时会持唤醒锁，屏幕不自动熄灭。倒计时归零会亮屏，**全屏白/黑闪烁 5 秒**
（250ms 一步），按任意键提前停止。

## 课表

数据存 LittleFS 的 `/tt.json`，最多 **72 条**，字段：课程名（≤24 字节 UTF-8，约 8 个汉字）、
星期、起止时刻、单双周、全局标记。

| 操作 | 按键 |
|---|---|
| 进课表页 | 菜单第 5 项，或长按 `#` 输 `111` |
| 上下翻 | `0` / `1`（可长按连发） |
| 换看星期几 | `#` 短按循环「今天 → 周一 … 周日」，`#` 长按回今天 |
| 回主页 | `*` 短按 |

- 进页面自动把光标落在「正在上」或「下一节」上，今天上完了就停在最后一节。
- **事件**：起止时间相同（单点）的行，列表里显示成「· 12:10 午餐」，不会当「正在上」。
- **全局事件**（`g=1`）：每天都算，只出现在主页第 4 行尾巴，不进课表列表的时间线。
- 单双周按 **ISO 周数**奇偶判定（奇数周 = 单周），不用配学期起始日；RTC 没校时按单周算。
  学校口径整体反相时，App 里「单双周互换」一键对调，每周都上的课不受影响。
- 整表下发走 `settt` 分片：设备边收边落盘到 `/tt.tmp`，最后用整表 FNV-1a 校验，
  对得上才解析替换；丢包或写坏整份丢弃，旧课表不动。

## 阅读器

只收 `.ezzbk`（ezbk 的小存储压缩版），转换在 [neobook](https://github.com/wzmwayne/neobook)
或 [tools/ezbk2ezzbk.py](tools/ezbk2ezzbk.py) 里做，设备不解析 ezbk 文本。

### 容器 v0.1（小端）

```
偏移 0   "EZZB"            4B 魔数
偏移 4   u8  algo          0=LZ4，1=raw deflate（16KB 窗口）
偏移 5   u8  flags         保留，写 0
偏移 6   u16 reserved      保留，写 0
偏移 8   u32 rawSize       解压后正文长度
偏移 12  u32 blockSize     固定 16384
偏移 16  u32 blockCount    块数（空正文时为 1）
偏移 20  u32 metaLen       元数据区长度
偏移 24  meta[metaLen]     UTF-8，每行 key=value：title / writer / intro / source / date
之后      u32 off[blockCount+1]  各块绝对偏移，最后一项等于文件长度
之后     各块压缩数据
```

- 第 k 块解压长度 = `min(blockSize, rawSize - k*blockSize)`，随机读只解一块。
- deflate 块用 ESP32-C3 ROM 里的 `tinfl_decompress` 解（约 11KB 状态，按需 malloc）。
- 书名优先取 `meta` 里的 `title`，没有才退回文件名；列表选中行放不下就走马灯。
- 兼容两种旧头：20 字节（有 algo/flags、无 metaLen）和 16 字节（只有 LZ4）。
  三种布局字段位置重叠，只能靠 `off[0] == 头部长度`、`off[count] == 文件长度` 对账区分。
- 正文里的 `#` 卷名、`##` 章名保留，设备扫描它们生成目录（最多 96 条）。

### 操作

| 位置 | 按键 | 作用 |
|---|---|---|
| 书目 | `0`/`1` | 上下选书 |
| 书目 | `#` | 打开选中那本 |
| 正文 | `0`/`1` | 上一页 / 下一页（长按连翻） |
| 正文 | `#` | 目录（自动定位到正在读的这章） |
| 正文 | `*` | 回书目（停一下自动存进度） |
| 目录 | `0`/`1` / `#` / `*` | 选章 / 跳转 / 回正文 |

排版：无标题栏，4 行 × 15px 铺满，底部 1px 进度条；**按像素宽度折行**（不做标点避头尾），
放不下的字留在下一行开头，所以不会重复也不会丢字。卷/章标题整行反白。

进度按文件名存在 NVS（`rd` 命名空间的 `idx`），文件删掉时对应进度一并清除。

## 蓝牙配置

设备名 `OLED-Panel`，单服务单特征一问一答，不做系统配对绑定；安全靠 6 位 PIN
（错 3 次断开并重启服务）。协议见 [docs/ble-protocol.md](docs/ble-protocol.md)。

进「蓝牙配置」页（编号 `101`）会显示 PIN 与状态；等手机连上后 PIN 才对得上。
短按 `*` 清配对并重启服务，长按 `*` 回主页。

手机 App（`android/`）：扫描连接 → 命令台（自检、时间、时区、课表、书库、解除配对）
→ 课表界面（网格编辑、事件/全局事件、导入导出 JSON）→ 通信日志。

## 字库

`font.bin` 放 font 分区，固件里只有声明（`src/font_wqy14.h`）。共 **21419 个字形**，
每个 32 字节（16×16，不描边），合计 685408 字节 ≈ 669 KB：

- ASCII + Latin-1 补充（U+00A0–U+00FF）
- 通用标点（U+2000–U+2070）、CJK 标点（U+3000–U+3040）、全角形式（U+FF01–U+FF66）
- GB2312 一级 + 二级汉字，以及 U+4E00–U+9FFF 全部 CJK

重新生成（生成完要刷整包）：

```bash
python3 tools/genfont_c.py              # 默认常用集
python3 tools/genfont_c.py --full       # 全 CJK
python3 tools/genfont_c.py --chars "测试屏幕"
```

未收录的字符按 8px 空心方框前进。固件启动时会核对字库首尾字形号，
不匹配就关掉字库（不出字）并写日志，不会画出满屏白块。

## 故障判读

| 现象 | 结论 |
|---|---|
| 串口没有输出 | fqbn 漏了 `:CDCOnBoot=cdc` |
| 屏幕只有白块 | 字库分区内容与固件版本不符，刷整包 |
| 花屏但 I2C 错误 = 0 | 多半是 SH1106，改 `OLED_CONTROLLER` |
| I2C 错误 > 0 | 电气问题：缩短线、查上拉、外接 4.7k |
| 整屏左移 2 像素 | SH1106 |
| 只亮上半屏 / 上下重复 | 是 128×32 不是 128×64 |
| 蓝牙扫不到 | 固件没跑起来 / 手机没给「附近的设备」权限 |
| 书上不去 | 不是 `.ezzbk`、名字超 32 字节，或空间不足 |
